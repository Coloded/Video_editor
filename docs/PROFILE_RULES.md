# Согласованные правила профилей

Зафиксировано 2026-09-06. Правила сортировки, позиции исходника и доступности реализованы в локальной сборке с режимом YouTube.

- Профили сортируются по прогнозируемому размеру результата, от меньшего к большему.
- Строка исходного файла находится среди них на позиции его фактического размера; это не шкала качества.
- Исходный профиль без перекодирования выбран при загрузке. Видео и оставленные аудиодорожки копируются без изменений, создаётся новый файл.
- Обычный профиль доступен, если прогноз меньше исходного файла. Номинальное разрешение/fps больше не блокирует выбор: фактический результат ограничен разрешением и fps исходника. Название «до 720p» обозначает верхнюю границу; для 720×256 результат остаётся 720×256. Учитываются пропорции и ориентация.
- Недоступные профили остаются в списке просто серыми, без пояснений в названии; выбрать их нельзя.
- Прогноз учитывает длительность, выбранные аудиодорожки, битрейт и кодек. Изменение выбора дорожек пересчитывает размеры, порядок и доступность. Пока выбранный профиль допустим, он не переключается.
- Слева параметры исходника, справа результат. Технические сообщения остаются отдельным блоком ниже.
- Добавления озвучки в разделе сжатия нет.

# Исследование режима YouTube

В локальной сборке реализован отдельный режим YouTube SDR: 240p–8K, H.264, MP4 по умолчанию при выборе профиля, исходная частота кадров, AAC 384 кбит/с. Для 4K выбраны 40/60 Мбит/с, для 8K — 120/180 Мбит/с из официальных диапазонов. 240p — собственная настройка 0.6/0.9. HDR и отдельный компактный режим остаются предложением, не реализованы как новые YouTube-профили. Профили редактируются существующим редактором; это подготовка файла к загрузке, без гарантии отсутствия потерь. Сквозной экспорт реального 8K-ролика пока не проверен.

Источники проверены 2026-09-06:
- https://support.google.com/youtube/answer/1722171?hl=en-GB
- https://support.google.com/youtube/answer/6375112?hl=en-AW
- https://support.google.com/youtube/answer/7126552?hl=en

Разрешения 16:9: 240p 426×240; 360p 640×360; 480p 854×480; 720p 1280×720; 1080p 1920×1080; 1440p 2560×1440; 2160p 3840×2160; 4320p 7680×4320. Сохранять пропорции других исходников.

Рекомендованный видеобитрейт SDR, Мбит/с, 24/25/30 fps и 48/50/60 fps:
- 240p: официального значения в таблице загрузки нет; свой профиль не выдавать за рекомендацию YouTube.
- 360p: 1 / 1.5
- 480p: 2.5 / 4
- 720p: 5 / 7.5
- 1080p: 8 / 12
- 1440p: 16 / 24
- 2160p: 35–45 / 53–68
- 4320p: 80–160 / 120–240

HDR в той же таблице: 720p 6.5/9.5; 1080p 10/15; 1440p 20/30; 2160p 44–56/66–85; 4320p 100–200/150–300. Для 360p/480p указано отсутствие поддержки HDR. Эти диапазоны нельзя объявлять отдельной официальной таблицей битрейтов HEVC/AV1.

SDR: MP4 Fast Start, H.264, progressive, BT.709, исходная fps; звук AAC-LC/Opus, 48 кГц (документация также перечисляет Eclipsa). Рекомендованный звук: mono 128, stereo 384, 5.1 512 кбит/с.
HDR: HEVC/VP9 Profile 2/AV1, 10/12 бит, BT.2020, PQ/HLG и корректные метаданные.

Предложение: «YouTube — рекомендованный SDR», «YouTube — компактный» (собственная настройка, не официальные битрейты HEVC), «YouTube HDR». Не увеличивать разрешение/fps ради названия профиля. Уточнять размер пробными фрагментами.

Снижение 5 ГБ до 3 ГБ не доказывает отсутствие потерь. Перекодирование с потерями может быть визуально незаметным, но не побитово идентичным. Без перекодирования можно исключить лишние дорожки/данные; заранее обещать 40% экономии нельзя. Причину размера конкретного экспорта подтверждать анализом файла.

# RUTUBE: рекомендации для загрузки

Проверено 2026-09-06: https://rutube.ru/info/upload/

- До 25 ГБ, до 5 часов.
- В списке рекомендованных разрешений: 144p, 240p, 360p, 480p, 720p, 1080p, 1440p, 2160p.
- В общих параметрах видео: битрейт выше 3600 кбит/с, до 3840×2160, 60 fps, ключевой кадр каждый 50-й. Отдельной таблицы битрейтов по разрешениям на этой странице нет.
- AAC-LC stereo, 128 кбит/с. Указано «44100 KHz»: очевидно ошибочная единица; 44100 Гц = 44.1 кГц.
- Вертикальное видео разрешено; поля для 16:9 добавлять в файл не нужно.
- Не повышать fps до 60 или разрешение ради этих общих рекомендаций без отдельной необходимости.
- Реализован отдельный каталог RUTUBE SDR 144p–4K: H.264, AAC 128 кбит/с, MP4 по умолчанию при выборе профиля. Битрейты — собственные настройки приложения: 144p 0.3/0.45; 240p 0.6/0.9; 360p 1/1.5; 480p 2.5/4; 720p 5/7.5; 1080p 8/12; 1440p 16/24; 2160p 40/60 Мбит/с для обычной/высокой исходной fps. Это не официальная таблица RUTUBE и не отдельный движок: действуют параметры общего кодировщика, включая звук 48 кГц. Параметры прямых трансляций и рекламных роликов сюда не переносить.

# Расположение переключателя

Под строкой файла и перед профилем расположен переключатель «Основной / YouTube / RUTUBE». Он меняет каталог выпадающего меню профилей. В верхней панели остаются только «Сжатие / Редактор». В редакторе переключатель каталогов скрыт, во время обработки недоступен. Выбранный профиль запоминается отдельно для каждого каталога; файл и выбранные аудиодорожки при переключении сохраняются.

Уточнение: битрейты маленьких профилей RUTUBE исправлены для сжатия. Они ниже общего порога 3.6 Мбит/с из справки платформы; это собственные настройки приложения, а не утверждение о полном соответствии официальной рекомендации.
