# Video Editor 3.8.2

- Перетаскивание роликов стало наглядным: открытая рука при наведении и закрытая рука при удержании кнопки мыши.
- Перемещаемая строка следует за курсором, а разрыв между строками заранее показывает точное место вставки.
- Отпущенный ролик вставляется между выбранными роликами, остальные элементы автоматически сдвигаются.
- Предпросмотр редактора непрерывно воспроизводит все выбранные фрагменты как единый проект.
- После окончания фрагмента автоматически выбирается следующий ролик, список прокручивается к нему, а воспроизведение продолжается без повторного нажатия Play.
- Общий указатель воспроизведения движется по всей монтажной последовательности и останавливается после последнего ролика.
