# Video Editor 3.7

- Добавлена безопасная проверка обновлений через Sparkle 2.
- В меню приложения появилась команда «Проверить обновления…».
- Приложение автоматически проверяет наличие новой стабильной версии и спрашивает подтверждение перед установкой.
- Для каждого релиза создаётся постоянный образ `Video_Editor-stable.dmg`.
- Обновления проверяются криптографической подписью EdDSA перед установкой.
