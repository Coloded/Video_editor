# Video Editor 3.11.0

- Переключатель «Основной / YouTube / RUTUBE» под файлом меняет список профилей. YouTube SDR — до 8K; собственные профили RUTUBE SDR — до 4K.
- Профили сортируются по прогнозируемому размеру, исходное качество находится среди них на позиции размера исходника. Все профили с меньшим прогнозом активны; остальные отображаются серыми.
- Разрешение и частота кадров при сжатии не увеличиваются: профиль «до 720p» сохраняет 720×256 у исходника такого размера.
- Исправлены завышенные битрейты маленьких профилей RUTUBE и отказ движка по исходному видеобитрейту при меньшем прогнозе результата.
- Выбор аудиодорожек для сохранения, исключение через контекстное меню и восстановление всех дорожек.
- «Исходное качество» копирует видео и выбранные дорожки без перекодирования в новый файл.
- Сравнение «Исходник / Результат» в двух колонках; технические сообщения сохранены.
- Проверки интерфейса и 17 тестов движка. Экспорт реального 8K-файла пока не проверен; перекодирование не гарантирует отсутствие потерь.
